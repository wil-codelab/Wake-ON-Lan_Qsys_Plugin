# Wake-ON-LAN Plugin for Qsys Core
This Plugin allows user(s) to wake up device on the network.

## How to Use
1. Add Plugin to your project.
2. Type-in Device name in the `Device Name` field. (Optional)
3. Type-in MAC address of the device you want to wake up in the `MAC Address` field. (Required)
4. Click `Send` button to send the Wake-ON-LAN packet to the device.
5. Expose Control Pins for other controls (Optional)
